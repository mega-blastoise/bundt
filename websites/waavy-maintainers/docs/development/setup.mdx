# Setup

## Prerequisites

| Tool | Version | Needed for |
|---|---|---|
| Bun | ≥ 1.3 (CI uses the latest 1.3.x) | everything TypeScript |
| Node + npm | 22+ | the launcher tests, `npm pack`, the install test |
| Rust | ≥ 1.85 (stable for development) | `crates/waavy` |
| Playwright Chromium | via `bunx playwright install chromium` | `bun run test:e2e` |
| Docker | optional | Linux, Alpine and cross-platform checks from a Mac |

## First run

```bash
git clone git@github.com:mega-blastoise/bundt.git && cd bundt
bun install
cd packages/waavy
bun run build
bun run test
```

`bun run test` compiles the host binary (`dist/bin/waavy`) first, then runs
everything under `src/` and `test/` (e2e excluded).

For the Rust side, from the repo root:

```bash
eval "$(scripts/waavy-rs-prepare.sh)"     # builds dist + binary + fixture release, exports WAAVY_BIN/WAAVY_RELEASE/…
cargo test -p waavy --all-features
```

## Working on the fixture

`packages/waavy/fixtures/basic` is a real workspace project (the root
`workspaces` includes `packages/waavy/fixtures/*`) with pages for each
behaviour the suites exercise:

| Page | Exercises |
|---|---|
| `counter` | props, hydration, hostile strings |
| `styled` | CSS import → manifest → `<link>` |
| `boundary` | error inside Suspense → recoverable |
| `broken` | shell throws → `RENDER_FAILED` |
| `slow` | never-resolving Suspense → deadline behaviour |

Try changes by hand:

```bash
cd packages/waavy
dist/bin/waavy build --root fixtures/basic --out /tmp/rel
dist/bin/waavy render --release /tmp/rel --page counter --props '{"label":"hi","initial":1}'
dist/bin/waavy serve --dev --root fixtures/basic --port 4100
```

## Linux from a Mac

Cross-compile and run in Docker — the fastest way to check Linux behaviour
before CI:

```bash
cd packages/waavy
bun build/binaries.ts --target linux-arm64 --target linux-arm64-musl
docker run --rm -v "$PWD":/w:ro debian:bookworm-slim /w/npm/linux-arm64/bin/waavy --version
docker run --rm -v "$PWD":/w:ro alpine:3.20 sh -c 'apk add -q libstdc++ libgcc && /w/dist/release-assets/linux-arm64-musl/waavy --version'
# x64 under emulation:
bun build/binaries.ts --target linux-x64
docker run --rm --platform linux/amd64 -v "$PWD":/w:ro debian:bookworm-slim /w/npm/linux-x64/bin/waavy --version
```

The install test also runs in a container:

```bash
docker run --rm -v "$PWD":/repo:ro -w /repo node:24-bookworm bash -c \
  'npm i -g bun@1.3 >/dev/null && scripts/waavy-install-test.sh --skip-build'
```

(Build `dist/` and the matching `npm/linux-<cpu>/bin` on the host first.)
